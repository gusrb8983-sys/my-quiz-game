## 6. 데이터 파일 설명 (state.json)

- 위치: 프로젝트 루트 (`./state.json`)
- 역할: 추가한 퀴즈와 최고 점수를 저장해, 프로그램을 껐다 켜도 유지되게 합니다.
- 인코딩: UTF-8
- 구조(스키마):

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ],
  "best_score": 0
}
```

- `quizzes`: 퀴즈 목록 (문제/선택지 4개/정답 번호)
- `answer`: 정답 번호 (1~4)
- `best_score`: 지금까지의 최고 점수
